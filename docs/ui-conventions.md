# UI Conventions

House rules for the fluxboard web UI.

## Layout and spacing

- Use the shared spacing scale; no ad-hoc pixel values for margins.
- Panels align to a common grid — a new widget should fit without custom offsets.

## Feedback

- Every user action gets visible feedback within one interaction, even if it is only a disabled state.
- Errors are human-readable first, technical details second.

## Copy

- Sentence case for headings and buttons.
- Avoid shipping unexplained jargon; name features the way users do.

When in doubt, copy an existing pattern instead of inventing one.
